# 🎵 Spotify Clone  

A responsive **Spotify Clone** built using **HTML, CSS, JavaScript, and Bootstrap**.  
This project replicates the core UI of Spotify and provides a clean, user-friendly music player interface.  

---

## 🚀 Features
- 🎶 Modern and responsive design with **Bootstrap**
- 📱 Mobile-friendly layout
- ▶️ Play / Pause music controls
- ⏭️ Next & Previous track functionality
- 🔊 Volume control
- 🎨 Custom styling with **CSS3**
- ⚡ Interactive UI using **JavaScript**

---

## 🛠️ Tech Stack
- **HTML5** – Structure of the web app  
- **CSS3** – Custom styling & animations  
- **JavaScript (ES6)** – Functionality and interactivity  
- **Bootstrap 5** – Responsive and modern UI components
